# Website Portfolio

A vanilla JavaScript personal portfolio website showcasing projects and skills with a clean, professional design.

![Portfolio Screenshot](./screenshot.png)

**🔗 Live Demo:** [View Live Demo](https://kevinwangombe.github.io/website-portfolio)

## ✨ Features

- Hero section
- About me
- Skills section
- Projects showcase
- Contact information
- Responsive design
- Smooth animations

## 🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- Vanilla JavaScript
- No frameworks - pure web technologies

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/kevinwangombe/website-portfolio

# Open index.html in browser
# Or use a local server:
npx serve
```

## 📁 Project Structure

```
├── index.html     # Main HTML file
├── style.css      # All styles
├── script.js      # Interactivity
└── images/        # Assets
```
